# Yayını tamamlama

Repo: https://github.com/harunsins/zelda-oot-turkce-yama

Yayın dosyaları (`index.html`, `README.md`, `KURULUM.md`, `favicon.svg`, `.nojekyll`) depoya gönderildi. **Asıl ZIP dosyası henüz GitHub'a aktarılmadı.**

## İndirme dosyasını ekleme

1. `downloads` klasörünü aç: https://github.com/harunsins/zelda-oot-turkce-yama/tree/main/downloads
2. `Add file → Upload files` ile `Zelda_OOT_Turkce_Yama_v0.4.3.zip` dosyasını yükle.
3. Dosyayı commit et ve SHA-256 değerinin `5338918d8d0ebcf1c300c4a8a1c4f3a07540d35849186e78bd1a8731a0a17438` olduğunu doğrula.
4. `index.html` sayfasındaki "GitHub deposunu aç" düğmesinin indirme yolu `downloads/Zelda_OOT_Turkce_Yama_v0.4.3.zip` olarak güncellenmeli.

## GitHub Pages

1. https://github.com/harunsins/zelda-oot-turkce-yama/settings/pages adresini aç.
2. `Build and deployment` → `Source: Deploy from a branch` seç.
3. `Branch: main`, dizin `/(root)` seç ve kaydet.
4. Yayın durumu başarılı göründükten sonra https://harunsins.github.io/zelda-oot-turkce-yama/ adresini doğrula.

## Telif uyarısı

Paketin içinde değiştirilmiş oyun kaynakları vardır. Açık yayın için hak sahiplerinin izni ya da yalnızca değişiklikleri içeren alternatif dağıtım biçimi değerlendirilmelidir.

Gerçek oyun içi kapsamlı doğrulama tamamlandı iddiasında bulunulmaz.
